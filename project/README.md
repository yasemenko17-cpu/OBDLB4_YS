# Наскрізний проєкт: аналітичні запити й індекси

Ця тека продовжує проєкт із лабораторної роботи 2 (базу вашого дипломного проєкту). Скопіюйте сюди з нього все, що стосується бази: `migrations/`, `data/`, `make_data.py`, `load.psql`, `post_load.sql` (і за бажанням `integrity_checks.sql`, `er_model.json`, `schema.sql`, `data_dictionary.md`). Потім додайте теку `analytics/`:

- `scale.sql`: SQL-скрипт, що доводить найбільшу таблицю проєкту щонайменше до 100 000 рядків засобами `generate_series` (без `random()`; значення виводяться з номера рядка), додаючи за потреби батьківські рядки;
- `q01_....sql` ... `q06_....sql`: п'ять або шість аналітичних запитів, кожен з рядком `-- title: короткий опис` (серед них хоча б один із CTE, один із віконною функцією, два з JOIN, один з GROUP BY та агрегатом);
- `indexes.sql`: команди `CREATE INDEX`, що прискорюють два з запитів;
- `analytics.json`: поле `optimized` із назвами двох прискорених запитів, наприклад `{"optimized": ["q02", "q05"]}`;
- `REPORT.md`: розділи `## Запити`, `## План до і після` (для кожного прискореного запиту підрозділ `### q02` з двома блоками коду: текст EXPLAIN до індексу й після) та `## Висновок`.

Розгорнути проєкт у схемі `project` вашої бази: `python project_check/deploy_project.py`.
Перевірити: `pytest project_check` (потрібен запущений PostgreSQL). Кожну зміну міграцій і кожну версію аналітики фіксуйте окремим комітом.
